# 企画書（2作目・改訂版）

## コンセプト

令和のスマホ（元は平成で死んだ高校生の魂）が、17年前の平成にタイムスリップする。
降った先は、初恋の人の17歳の姿の膝の上。しかも、この夜、「死ぬ予定の自分」がいる。

- 意味不明なインパクト: **スマホが平成に落ちてくる／死ぬ予定の自分がいる／17年遅れの返事が送り返される**
- 読者の疑問: **スマホは、17歳の彼女に、何を伝えられる？ 自分は助かる？**
- 感情の山: ふたりの喧嘩（ホワイトデー）→ 22時40分のブレーキ音 → 公園の3人 → 17年後の写真

## タイトル案

1. **スマホだった俺が平成にタイムスリップしたら、持ち主は初恋の君で、死ぬ予定の俺がいた**（採用）
2. 17年遅れの返事は、17年前の君に届いた
3. 令和のスマホ、平成のバス停に落ちる。死ぬ予定の俺を助けるために

## 設定

- 語り手: 俺（元は蒼太。スマホに転生した魂）
- 17歳の蒼太: 「死ぬ予定の俺」。口が悪いが、ほんとうは優しい
- ヒロイン: 美咲（17歳／34歳）
- 友人: 麻衣（電話だけ出演）
- 名前は現代的な漢字（2作目のみ、カタカナ縛りの例外）

## 時系列

| 日時 | 出来事 |
|---|---|
| 2008年3月14日 昼 | 蒼太と美咲が喧嘩 |
| 2008年3月14日 21時58分 | スマホ、バス停の美咲のひざに落ちる |
| 2008年3月14日 22時12分 | 蒼太が美咲にメールを送る |
| 2008年3月14日 22時31分 | 美咲が未来の送信済みメールを読む |
| 2008年3月14日 22時38分 | 美咲が蒼太に電話。22時40分にトラックが横を通過 |
| 2008年3月14日 23時 | 公園で3人（2人と1台）が笑う |
| 2025年3月14日 | 17年間引き出しにいたスマホが、充電される。34歳の蒼太と美咲が写真を撮る |

2025年3月14日の21時58分に、34歳の美咲が17年遅れの返事を送信する。その瞬間、スマホは2008年3月14日の21時58分に落ちる（冒頭の回想）。

## ランキングを狙う工夫

- **タイトル**: 状況をぜんぶ説明する長文タイトル。なろうの一覧で最も目に止まる形式。
- **あらすじ冒頭**: 「スマホだった俺が、平成にタイムスリップした。」→「なんで？ 俺にもわからない。」で、笑いと謎を同時に出す。
- **前半**: ツッコミ多めの軽いテンポで、読者に抵抗なく入ってもらう。
- **後半**: 「22時40分」から一気に感情を動かす。
- **ラスト**: 別の未来の写真と、いまの笑顔を重ねる。
- **キーワード例**: `タイムスリップ` `スマホ` `平成` `切ない` `初恋` `ホワイトデー` `ハッピーエンド` `コメディ`

# 企画書（2作目）

## コンセプト

平成（2008年）に17歳で亡くなった少年が、令和（2025年）に、好きだった女の子のスマホとして転生する。
できることは「アラーム音」「バイブレーション」「画面の明るさ」「予測変換」だけ。
17年間未読のままのガラケーのメールを、彼女が開く日までの物語。

- 読者が最初に知りたくなる謎: **スマホになった僕と、34歳の美咲はどうなる？ 未読のメールには何が？**
- 回収: メールの全文（告白）、予測変換の「すき」、バッテリー99%の奇跡
- 感情の山: 再会（目覚め）→ 未読メールの告白 → 予測変換の「すき」→ バイブ1回

## タイトル案

1. **平成で死んだ僕は、令和のスマホになって、好きだった君の手に渡った**（採用）
2. 17年間未読だったメールを、スマホになった僕は見ていた
3. 転生したらスマホだった。しかも持ち主は初恋の君だった

## 設定

- 語り手: 蒼太（17歳で死亡）。スマホとして転生
- ヒロイン: 美咲（17歳→34歳）。会社員、ひとり暮らし
- 友人: 麻衣（美咲の親友）
- 時間軸: 2008年3月14日（死亡） / 2025年1月（スマホとして起動） / 2025年3月14日（未読メールを開く）
- アイテム: ピンク色のガラケー、クマのストラップ、プリクラの待ち受け、クッキー、予測変換

## 時系列

| 日付 | 出来事 |
|---|---|
| 2008年3月14日 22時12分 | 蒼太が美咲にメールを送る（美咲は未読のまま） |
| 2008年3月14日 22時40分 | 蒼太が事故で死亡 |
| 2025年1月 | 美咲の34歳の誕生日（1月）に、スマホ（5万4800円）として起動 |
| 2025年3月14日 | 美咲がガラケーを充電し、17年ぶりにメールを開く |

## ランキングを狙う工夫

- **タイトル**: 「平成で死んだ」「令和のスマホ」「好きだった君の手」という対比と転生ネタで、一覧で目に止まる。
- **冒頭**: 「目が覚めた、と思った。でも、目はなかった。」で1行目から異変を見せる。
- **泣かせどころ**: 手も足もない主人公が、予測変換の1語だけで想いを伝える。
- **ラスト**: 「明日も、6時30分に、君を起こすから。」で温かい余韻。
- **キーワード例**: `転生` `スマホ` `平成` `切ない` `初恋` `ホワイトデー` `ハッピーエンド`

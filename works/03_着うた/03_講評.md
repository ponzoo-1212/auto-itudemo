# 講評（3作目）

## 総評
タイトルの謎「なぜ1年間いちども鳴らなかった？」が、ラストでふたりの想いの重なりとして回収される。仕掛けは小さいが、構造はいちばんきれい。

## 良い点
- 着うたを選ぶ冒頭で、2008年に引き込める。
- 3時12分の夜中のやりとりで、友だち以上の距離を表現できている。
- 「リカのケータイは鳴らした。でも、俺のケータイは、鳴らなかった。」の一文が、タイトルと矛盾しないよう計算されている。
- 目の前で着うたが鳴るラストは、場面として絵になる。

## 問題点（訂正対象）
1. 時間設定の矛盾: 「高校2年の春」から1年後に卒業式はない。高校3年の春にする必要がある。
2. 元カレ（ショウ）が「2コ上のサッカー部」だと、同じ高校の先輩として年齢が合わない。
3. 夜中の通話のあと、リカがショウと別れない理由が薄い。
4. 第5場でリカが「夜中に電話しちゃって」と言うが、電話をかけたのはユウ。
5. ユウが踏み出せない理由（自分から友だちを壊す勇気がない）が、はっきり書かれていない。

## 評価
- フック: A- / 感情の山: B+ / 完成度: B → 訂正後はA-

# 第2回講評（全文を最初から通読）

## 問題点
1. 兄貴の台詞（「ユウ、なにしてんの」）の話し手が、直前に書かれていない。
2. 「ずるい」が誰のことか不明。
3. ユウが「ショウに送るメールが俺のところに来るわけがない」と判断する根拠が弱い。
4. リカの一人称が「私」と「あたし」で揺れていた（第6場）。
5. リカがユウのケータイを借りたまま、「そのケータイ持ってて」と言う（返していない）。
6. ユウが「好きだ」と明言しておらず、告白の返事が曖昧。

## 評価（第2回）
- 上記6点を訂正後、再通読して新たな問題は見つからなかった。

# 第3回講評（わかりやすさの観点）

## 問題点
1. 「着うた」がわからない読者には、タイトルも物語も伝わらない。
2. ユウの名前と学年が、冒頭に出てこない。
3. リカ、ショウが再登場するとき、誰か思い出しにくい。
4. ラストのリカの台詞「ユウの着うたが鳴る」が、誰のケータイで何が鳴るのかあいまい。
